# Nothing on this site is blocked, to any crawler.
#
# The site was previously held out of search results by two things that had
# to come off together: the noindex meta tag on every page and an
# X-Robots-Tag header in .htaccess. Both are gone.
#
# Crawling was always allowed here even during development, and for a
# reason worth keeping in mind: "Disallow: /" would have stopped crawlers
# reading the noindex, so URLs already known to Google would have stayed in
# the index indefinitely.

User-agent: *
Allow: /

# The AI crawlers are named as well as covered by the wildcard above. Some
# of them treat an explicit record as the only one that applies to them, so
# a bare "User-agent: *" is not reliably read as permission.

Allow: /
